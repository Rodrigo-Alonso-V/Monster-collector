# Frontend - Monster Collector (Godot Engine)

Interfaz de usuario y cliente del juego desarrollado en **Godot Engine 4**.

---

Las capturas de la interfaz en ejecución se encuentran en la carpeta `Assets/Screenshots/`:

* **Inventario:** `Assets/Screenshots/Inventory.png`
* **Estadisticas de mountro:** `Assets/Screenshots/Statistics.png`

---

## 🛠️ Requisitos y Librerías

* **Motor:** Godot Engine 4.x
* **Lenguaje:** GDScript
* **Librerías / Módulos:** HTTPRequest (para consumo de API REST del Backend)

---

## 🚀 Ejecución del Proyecto

1. Abrir **Godot Engine**.
2. Hacer clic en **Importar** (Import).
3. Seleccionar el archivo `project.godot` ubicado dentro de esta carpeta (`game-monster-collector/project.godot`).
4. Presionar el botón **Ejecutar proyecto** (`F5`).
