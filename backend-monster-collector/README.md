# Backend - Monster Collector

API desarrollada con NestJS para el juego Monster Collector.

## 📁 Base de Datos

Los esquemas de validación, diagramas y scripts de MongoDB se encuentran localizados en:

* **Diagrama de colecciones:** `database/Collections.png`
* **Esquema de Usuarios:** `database/schemaUser.json`
* **Esquema de Monstruos:** `database/schemaMonster.json`
* **Documentación:** `database/README.md`

Aquí se encuentran los schemas generados en NestJS para validación al conectar con MongoDB.
