# Monster Collector 🎮👾

Proyecto integrador que comprende un videojuego en **Godot Engine**, un servidor backend en **NestJS** y una base de datos en **MongoDB**.

---

## 🛠️ Tecnologías Utilizadas

* **Frontend / Cliente:** Godot Engine 4 (GDScript)
* **Backend:** Node.js, NestJS, TypeScript, Mongoose
* **Base de Datos:** MongoDB
* **Pruebas de API:** Postman
